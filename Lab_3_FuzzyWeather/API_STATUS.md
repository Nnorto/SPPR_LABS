# Статус сетевой проверки лабораторной №3

## OpenWeatherMap

Последняя повторная проверка сохранённого нового ключа выполнена 21 октября 2026 года. Запрос Current Weather для Казани вернул HTTP 401, поэтому ответы текущей погоды для трёх городов не приложены.

Причина отказа по этому ответу не установлена: нельзя утверждать, что дело только во времени активации. Проверь соответствие ключа аккаунту и доступ к Current Weather; варианты ошибок описаны в [FAQ OpenWeatherMap](https://openweathermap.org/faq).

## Исторические источники

Open-Meteo при подготовке вернул HTTP 429 с сообщением об исчерпании дневного лимита. В качестве независимого допустимого источника получена реальная история NASA POWER / MERRA-2 за 2021–2025 годы.

Оригиналы NASA сохранены вместе с метаданными, а расчёт воспроизводится без повторных запросов. Исторический режим не является обходом авторизации или заменой текущего OpenWeatherMap.

## Как закрыть оставшийся пункт

На Mac активируй окружение, перейди в `Lab_3_FuzzyWeather` и выполни:

```bash
python setup_config.py
python main.py --refresh-current
```

Успех подтверждается тремя файлами в `data/current`, корректными временами наблюдений и завершением анализа с кодом 0. После этого в отчёт нужно добавить новые результаты и заменить статус ограничения; сейчас отчёт честно описывает только проверенный исторический запуск.
