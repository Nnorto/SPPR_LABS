# Лабораторная №4, вариант 11 — стартовый проект для Mac

Это рабочий каркас для интерактивного сбора, НЕ завершённая лабораторная. Реальные патенты не собраны, Selenium на сайте не проверен, Hadoop не запускался. Массовый обход всех номеров и полное извлечение полей ещё не реализованы.

## Быстрый запуск
Распакуйте папку Lab_4_Variant11 в labs_mac. В Терминале перейдите в эту папку:
```bash
/usr/local/bin/python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python collect.py
```
Нужен установленный Chrome. Selenium Manager попробует подобрать драйвер; для первой загрузки нужен интернет.

В Chrome откройте реестр изобретений, найдите карточку номера 1700000–1799999. Вернитесь в Терминал и введите `invention НОМЕР`. Для полезной модели диапазона 222000–222999 — `utility_model НОМЕР`. Навигация ручная: это намеренно безопасный первый этап проверки структуры. При капче/ограничении остановитесь; обход защиты не реализован. Для выхода `q`.

В data/raw сохраняются исходные HTML, в data/records — извлечённые записи. Парсер предполагает идентификаторы B542, Abs, bib из методички. Если их нет, он отказывается выдавать карточку за успешно разобранную. Отдельный номер пользователь вводит сам; проверка его присутствия в тексте не заменяет ручной проверки идентичности карточки.

Проверьте каждую запись по HTML, дополните нераспознанные поля, города/регионы авторов заполняйте только если они есть в источнике. Значения null и [] здесь означают «не извлечено», не «отсутствует».

```bash
python export.py
```
Будут созданы единый JSON, JSONL, CSV и отчёт качества. quality.json намеренно не объявляет работу готовой к сдаче: полная схема и полнота диапазонов не проверены. Для всех 101000 номеров нужен отдельный автоматический обход с ограничением частоты, возобновлением и журналом пропусков; этот релиз его не содержит.
