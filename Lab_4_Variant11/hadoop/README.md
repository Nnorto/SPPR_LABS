# Hadoop 3.4.2: отдельный этап

Загрузка пока НЕ выполнялась. Наличие скрипта не означает наличия Hadoop.
Официальная инструкция: https://hadoop.apache.org/docs/r3.4.2/hadoop-project-dist/hadoop-common/SingleCluster.html

Документация ориентирована на GNU/Linux. Для Mac нужно сначала определить способ установки: Linux VM либо проверенная локальная настройка. Не запускайте команды форматирования существующего NameNode.

После установки Java/Hadoop настройте core-site.xml: fs.defaultFS=hdfs://localhost:9000, hdfs-site.xml: dfs.replication=1. Для нового пустого учебного HDFS форматирование делается ОДИН раз. Затем запускаются NameNode и DataNode, проверяется http://localhost:9870/. Не открывайте учебный HDFS в интернет.

Когда HDFS уже работает, из корня проекта:
```bash
bash hadoop/upload.sh
```
Скрипт загружает единый JSON, сохраняет листинг, отчёт HDFS и SHA256 исходного и загруженного файлов. Хеши должны совпасть. Это проверка HDFS, не распределённая задача MapReduce и не Spark.

В методичке показана именно загрузка HDFS; Spark упомянут в заголовке без конкретной задачи. Если преподаватель требует обработку MapReduce/Spark, этот комплект её пока не реализует.
