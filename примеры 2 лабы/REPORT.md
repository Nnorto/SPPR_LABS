## Вводный пример: покраска

База `painting.pl` содержит цены красной, белой и синей покраски. Правило вычисляет площадь поверхности и умножает её на цену квадратного метра.

### Самостоятельные запросы «в» и «г»

Все варианты и цены:

```prolog
colour_cost(Colour, Price).
```

```text
red   1000
white 1030
blue  1070
```

Цена ниже 1050:

```prolog
colour_cost(Colour, Price), Price < 1050.
```

```text
red   1000
white 1030
```

### Три запроса с `colouring_cost/4`

Все варианты для поверхности 10 на 5:

```prolog
colouring_cost(10, 5, Colour, Cost).
```

Площадь равна \(10\cdot5=50\). Результаты: красная \(50\cdot1000=50000\), белая \(50\cdot1030=51500\), синяя \(50\cdot1070=53500\).

Варианты дешевле 52000:

```prolog
colouring_cost(10, 5, Colour, Cost), Cost < 52000.
```

Условию удовлетворяют красная и белая краски со стоимостью 50000 и 51500. Синяя стоит 53500 и отбрасывается сравнением.

Белая покраска поверхности 3 на 4:

```prolog
colouring_cost(3, 4, white, Cost).
```

Стоимость равна \(3\cdot4\cdot1030=12360\). Отрицательные размеры дополнительно запрещены проверками в правиле.

## Выбранное задание: родители и дети

В базе знаний `family.pl` девять фактов `родитель/2` и двенадцать уникальных людей. Это удовлетворяет требованиям минимум пять фактов и 10–15 участников.

Первые семь фактов сохранены из примера PDF. Добавлены связи Николай → Саша и Наталья → Денис; весь набор используется как учебная модель.

Список уникальных участников: Илья, Марина, Ира, Елена, Иван, Николай, Ольга, Алексей, Саша, Сергей, Наталья, Денис. Участник может быть одновременно родителем и ребёнком, как Марина.

## Правила базы знаний

- **`parents_of/2`:** собирает родителей заданного ребёнка в список.
- **`all_pairs/1`:** возвращает список всех отношений родитель–ребёнок.
- **`grandparent/2`:** выводит родство через две связи.
- **`person/1` и `all_people/1`:** собирают участников из обоих аргументов фактов и удаляют повторы.
- **`show_pairs/0`:** печатает отношения по одной записи на строку.

Таким образом, требование минимум двух правил выполнено. `findall/3` собирает все решения и возвращает пустой список, если совпадений нет: [описание SWI-Prolog](https://www.swi-prolog.org/pldoc/man?predicate=findall/3).

## Ответы на запросы задания

### Список родителей Ивана

```prolog
родитель(Parent, 'Иван').
```

Последовательно находятся Елена и Сергей. Одним списком:

```prolog
parents_of('Иван', Parents).
```

```text
Parents = ['Елена', 'Сергей'].
```

### Все родители и дети

```prolog
родитель(Parent, Child).
```

Результат состоит из девяти пар:

```text
Илья -> Марина
Марина -> Ира
Елена -> Иван
Николай -> Ира
Ольга -> Алексей
Марина -> Саша
Сергей -> Иван
Николай -> Саша
Наталья -> Денис
```

Для печати без ручного запроса следующего решения используется `show_pairs.`. Для получения списка вместо печати используется `all_pairs(Pairs).`.

## Дополнительный логический вывод

```prolog
grandparent('Илья', Child).
```

Ответы: Ира и Саша. Сначала правило находит Марину как ребёнка Ильи, затем её детей, не используя прямой факт об отношении через поколение.

Количество участников проверяется запросом:

```prolog
all_people(People), length(People, Count).
```

Ответ `Count = 12` получен после удаления повторов. Девять отношений не означают девять участников, потому что одна запись содержит двух людей, а одни и те же люди встречаются несколько раз.

## Приложение: полный листинг основных модулей

Тесты находятся в отдельных файлах комплекта. Ниже приведены исходники, формирующие результат.

### painting.pl

```prolog
:- encoding(utf8).

% Вводный пример из PDF. Цена указана за квадратный метр.
colour_cost(red, 1000).
colour_cost(white, 1030).
colour_cost(blue, 1070).

colouring_cost(Height, Width, Colour, Cost) :-
    number(Height), number(Width),
    Height >= 0, Width >= 0,
    colour_cost(Colour, ColourCost),
    Square is Height * Width,
    Cost is Square * ColourCost.
```

### family.pl

```prolog
:- encoding(utf8).

% Выбранное задание 1: родители и дети, записанные в библиотеку.
% 12 различных людей, 9 фактов родитель/2.
% Первые 7 фактов сохранены из методички. Последние 2 учебные.
родитель('Илья', 'Марина').
родитель('Марина', 'Ира').
родитель('Елена', 'Иван').
родитель('Николай', 'Ира').
родитель('Ольга', 'Алексей').
родитель('Марина', 'Саша').
родитель('Сергей', 'Иван').
родитель('Николай', 'Саша').
родитель('Наталья', 'Денис').

% Правило 1: получить всех родителей указанного ребёнка одним списком.
parents_of(Child, Parents) :-
    findall(Parent, родитель(Parent, Child), Parents).

% Правило 2: собрать все записи базы знаний.
all_pairs(Pairs) :-
    findall(Parent-Child, родитель(Parent, Child), Pairs).

% Правило 3: вывести новое отношение по цепочке из двух фактов.
grandparent(Grandparent, Child) :-
    родитель(Grandparent, Parent),
    родитель(Parent, Child).

% Два предложения одного предиката person/1.
person(Name) :- родитель(Name, _).
person(Name) :- родитель(_, Name).

% sort/2 удаляет повторы: Марина встречается в нескольких записях.
all_people(People) :-
    findall(Name, person(Name), Names),
    sort(Names, People).

show_pairs :-
    forall(родитель(Parent, Child),
           format('~w -> ~w~n', [Parent, Child])).
```
