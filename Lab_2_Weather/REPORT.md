## Цель и постановка задачи

Создать прототип экспертной системы на SWI-Prolog, которая использует факты о погоде и правила для выдачи рекомендаций. Основание: приложенный документ «Лабораторная 2 ЭС SWI prolog».

## База знаний

Предикат `weather/4` хранит город, температуру, погодное состояние и скорость ветра. Исходные температура и состояние первых трёх городов сохранены из задания; Екатеринбург добавлен по условию.

| Город | Температура | Состояние | Ветер |
|---|---:|---|---:|
| Москва | 5 | дождь | 7 |
| Санкт-Петербург | 2 | снег | 12 |
| Казань | -3 | снег | 4 |
| Екатеринбург | -15 | снег | 11 |

Скорости 7 и 12 взяты из примера задания. Для Казани и Екатеринбурга выбраны учебные значения 4 и 11, чтобы показать слабый и сильный ветер.

## Выполнение самостоятельных заданий

### Добавление города

Добавлен факт:

```prolog
weather('Екатеринбург', -15, снег, 11).
```

Запрос `show_all_advices.` выводит совет и для этого города. Температура ниже -10 выбирает рекомендацию одеваться максимально тепло.

### Учёт ветра

Везде выполнен переход с `weather/3` на `weather/4`. Предикат `wind_advice/2` использует три непересекающихся диапазона:

- **От 0 до 5, не включая 5:** слабый ветер.
- **От 5 до 10 включительно:** ветрено, застегнуть куртку.
- **Строго выше 10:** сильный ветер.

Отрицательная скорость отвергается. Скорость ровно 10 относится ко второму диапазону, что отдельно проверено тестом.

### Подбор активности

`activity_advice/3` возвращает одну активность. Пляж: выше 20 и солнечно; музей или кафе: дождь и от 15 до 25 включительно; лыжи: снег и ниже нуля; иначе общая прогулка.

Цепочка `if-then-else` исключает одновременное возвращение специальной и общей рекомендации. `advice_parts/2` собирает четыре части, после чего `advice_for/2` соединяет их в один атом.

## Как устроен вывод

На запрос `advice_for('Москва', A).` правило находит учебный факт о Москве. Затем по очереди выполняет температурное правило, правило состояния, правило ветра и правило активности.

Список частей превращается в итоговый атом с разделителем-пробелом через `atomic_list_concat/3`. Такое использование соответствует назначению предиката: [документация SWI-Prolog](https://www.swi-prolog.org/pldoc/man?predicate=atomic_list_concat/3).

`show_all_advices/0` печатает итог каждого решения через `forall/2`. Этот предикат здесь используется для действия вывода, а не для возвращения наружу списка переменных: [документация SWI-Prolog](https://www.swi-prolog.org/pldoc/man?predicate=forall/2).

## Проект №4: подсчёт нарушений

В файле `violations.pl` задано три автомобиля и пять нарушений с уникальными ID. Все данные вымышлены и служат только демонстрации.

```prolog
violation_count(Plate, Count) :-
    car(Plate, _),
    findall(ID, violation(ID, Plate, _, _), IDs),
    length(IDs, Count).
```

`findall/3` получает список ID, включая пустой список при отсутствии подходящих нарушений; затем `length/2` определяет количество. Возврат пустого списка для отсутствующих решений является свойством [findall/3](https://www.swi-prolog.org/pldoc/man?predicate=findall/3).

Результаты:

```text
А123АА116: 3
В456ВВ116: 2
Е789ЕЕ116: 0
```

Для первой машины найдены события 1, 2, 3, для второй 4, 5. Третья машина известна базе, но у неё нет событий; для неизвестного номера запрос возвращает `false`, а не 0.

## Ответы на контрольные вопросы

- **Факт и правило:** факт описывает исходную связь, например `weather('Москва', 5, дождь, 7).`; правило с `:-` задаёт условия получения нового результата.
- **Запрос с переменной:** `advice_for('Москва', A).` связывает `A` с советом; `advice_for(City, A).` перебирает города базы.
- **`forall/2`:** запускает действие для каждого решения условия, здесь печатает советы. Он не сохраняет полученные внутри связывания переменных как результат: [SWI-Prolog](https://www.swi-prolog.org/pldoc/man?predicate=forall/2).
- **Объединение текста:** используется `atomic_list_concat(Parts, ' ', FullAdvice)`. Результат является атомом; в учебном описании слово «строка» употреблено не как точное обозначение Prolog-типа: [SWI-Prolog](https://www.swi-prolog.org/pldoc/man?predicate=atomic_list_concat/3).

## Приложение: полный листинг основных модулей

Тесты находятся в отдельных файлах комплекта. Ниже приведены исходники, формирующие результат.

### weather.pl

```prolog
:- encoding(utf8).

% Лабораторная №2. Учебная база, НЕ текущий прогноз погоды.
% weather(Город, Температура_в_C, Состояние, Ветер_в_м_с).
% Ветер в Казани и Екатеринбурге выбран для учебного примера.
weather('Москва', 5, дождь, 7).
weather('Санкт-Петербург', 2, снег, 12).
weather('Казань', -3, снег, 4).
weather('Екатеринбург', -15, снег, 11).

% Непересекающиеся интервалы: [-10,0), [0,10), [10,20).
temp_advice(Temp, 'Очень холодно, одевайтесь максимально тепло!') :-
    number(Temp), Temp < -10.
temp_advice(Temp, 'Холодно, наденьте тёплую куртку и шапку.') :-
    number(Temp), Temp >= -10, Temp < 0.
temp_advice(Temp, 'Прохладно, возьмите ветровку или легкую куртку.') :-
    number(Temp), Temp >= 0, Temp < 10.
temp_advice(Temp, 'Тепло, можно гулять в джемпере или рубашке.') :-
    number(Temp), Temp >= 10, Temp < 20.
temp_advice(Temp, 'Жарко, лучше надеть футболку и шорты.') :-
    number(Temp), Temp >= 20.

cond_advice(дождь, 'Возьмите зонт, ожидается дождь.').
cond_advice(снег, 'Осторожно, снегопад, будьте аккуратны на дорогах.').
cond_advice(солнечно, 'Не забудьте солнечные очки и головной убор!').
cond_advice(облачно, 'Погода облачная, осадков не ожидается.').

% Ровно 10 м/с относится к среднему ветру, а не к сильному.
% Отрицательная скорость недопустима: такой запрос возвращает false.
wind_advice(Wind, 'Сильный ветер, будьте осторожны!') :-
    number(Wind), Wind > 10.
wind_advice(Wind, 'Ветрено, застегните куртку.') :-
    number(Wind), Wind >= 5, Wind =< 10.
wind_advice(Wind, 'Ветер слабый, комфортно.') :-
    number(Wind), Wind >= 0, Wind < 5.

% Входной режим: известны числовая температура и состояние.
% if-then-else обеспечивает ОДНУ рекомендацию, включая общий случай.
activity_advice(Temp, Cond, Activity) :-
    number(Temp),
    cond_advice(Cond, _),
    ( Temp > 20, Cond == солнечно ->
        Activity = 'Идеально для пляжа!'
    ; Temp >= 15, Temp =< 25, Cond == дождь ->
        Activity = 'Можно посетить музей или кафе.'
    ; Temp < 0, Cond == снег ->
        Activity = 'Хорошая погода для катания на лыжах.'
    ; Activity = 'Можно просто погулять по городу.'
    ).

% Части совета сохраняются отдельно: это помогает объяснить вывод.
advice_parts(City, [TempPart, CondPart, WindPart, Activity]) :-
    weather(City, Temp, Cond, Wind),
    temp_advice(Temp, TempPart),
    cond_advice(Cond, CondPart),
    wind_advice(Wind, WindPart),
    activity_advice(Temp, Cond, Activity).

advice_for(City, FullAdvice) :-
    advice_parts(City, Parts),
    atomic_list_concat(Parts, ' ', FullAdvice).

show_all_advices :-
    forall(advice_for(City, Advice),
           format('~w: ~w~n~n', [City, Advice])).

% ВАЖНО: правила дословно следуют учебному заданию.
% Они не оценивают безопасность прогулки/лыж при морозе и сильном ветре.
```

### violations.pl

```prolog
:- encoding(utf8).

% Проект №4: подсчёт нарушений для автомобиля.
% Все номера, владельцы и события вымышлены.
% car(Номер, Владелец).
car('А123АА116', 'Иван Петров').
car('В456ВВ116', 'Анна Сидорова').
car('Е789ЕЕ116', 'Олег Иванов').

violation_type(speeding, 'Превышение скорости').
violation_type(parking, 'Нарушение правил парковки').
violation_type(red_light, 'Проезд на запрещающий сигнал').

% violation(ID, Номер, Тип, Дата).
% Разные ID обозначают разные события, даже с одинаковым типом.
violation(1, 'А123АА116', speeding, date(2026, 9, 1)).
violation(2, 'А123АА116', parking, date(2026, 9, 2)).
violation(3, 'А123АА116', speeding, date(2026, 9, 3)).
violation(4, 'В456ВВ116', red_light, date(2026, 9, 4)).
violation(5, 'В456ВВ116', parking, date(2026, 9, 5)).

% car/2 позволяет перечислять известные машины и отличает неизвестную
% машину (false) от известной без нарушений (Count = 0).
violation_count(Plate, Count) :-
    car(Plate, _),
    findall(ID, violation(ID, Plate, _, _), IDs),
    length(IDs, Count).

show_violation_counts :-
    forall(violation_count(Plate, Count),
           format('~w: ~d~n', [Plate, Count])).
```

### demo.pl

```prolog
:- encoding(utf8).
:- ensure_loaded(weather).
:- ensure_loaded(violations).

demo :-
    set_stream(user_output, encoding(utf8)),
    writeln('ЛАБОРАТОРНАЯ №2. УЧЕБНЫЕ ДАННЫЕ'),
    show_all_advices,
    writeln('Границы ветра:'),
    forall(member(W, [0, 4.9, 5, 10, 10.1]),
           (wind_advice(W, A), format('~w м/с: ~w~n', [W, A]))),
    nl, writeln('Активности:'),
    forall(member(T-C, [21-солнечно, 15-дождь, 25-дождь, -1-снег, 0-снег]),
           (activity_advice(T, C, A),
            format('~w C, ~w: ~w~n', [T, C, A]))),
    nl, writeln('Проект №4. Число нарушений:'),
    show_violation_counts.
```
